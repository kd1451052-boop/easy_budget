# Easy Budget
## english language is below 👇

Easy Budget は、AIの力と直感的なデザインを組み合わせた、Flutter製の強力で使いやすい家計簿・予算管理アプリです。レシートをスキャンするだけで自動的に支出を記録し、スマートに資産を管理できます。

## 主な機能 (Highlights)

*   **🤖 AI レシートスキャナー**: `google_generative_ai` とカメラ/ギャラリーを利用して、レシートから自動的に支出データを抽出して記録します。
*   **📊 ビジュアルデータ分析**: `fl_chart` による美しいチャートで、支出や予算の状況を一目で把握できます。
*   **🗓️ カレンダービュー**: `table_calendar` を組み込み、日々の取引履歴をカレンダー上で簡単に確認・管理できます。
*   **🎯 予算＆貯金トラッキング**: カスタマイズ可能な予算設定と、目標に向けた貯金トラッキング機能を搭載。
*   **⚡ 高速なローカル保存**: `Hive` を使用したセキュアでオフライン対応のローカルデータベース。
*   **📱 モダンなUI & 状態管理**: `Provider` を使用した効率的な状態管理と、シームレスなユーザー体験。

## 始め方

1. リポジトリをクローンします。
2. `flutter pub get` を実行して依存関係をインストールします。
3. `google_generative_ai` 用のAPIキーを設定してください。
4. `flutter run` でアプリを起動します！

# Easy Budget 

Easy Budget is a powerful, user-friendly personal finance and budgeting app built with Flutter. It combines intuitive design with the power of AI to help you effortlessly manage your expenses, track savings, and stay on top of your financial goals.

## Highlights & Features

*   **🤖 AI Receipt Scanner**: Automatically extract and log expenses from your receipts using `google_generative_ai` and the device camera/gallery.
*   **📊 Visual Data Analysis**: Get a clear overview of your spending habits and budgets with beautiful, interactive charts powered by `fl_chart`.
*   **🗓️ Calendar View**: Easily track and manage your daily transactions directly on a calendar using `table_calendar`.
*   **🎯 Budget & Savings Tracking**: Set customized budgets and track your savings progress towards your financial goals.
*   **⚡ Fast Local Storage**: Secure, offline-first local database utilizing `Hive`.
*   **📱 Modern UI & State Management**: Seamless user experience with efficient state management using `Provider`.

##  Getting Started

1. Clone this repository.
2. Run `flutter pub get` to install dependencies.
3. Configure your API key for `google_generative_ai` to enable the AI scanner features.
4. Run `flutter run` to start the app!
